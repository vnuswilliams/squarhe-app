# Ajouter un employé

Bienvenue dans ce tutoriel rapide pour créer un nouvel employé dans l'application.

## 1) Ouvrir le module Employés

- Depuis la barre latérale, cliquez sur **Employés**.
- Cliquez ensuite sur **Ajouter un employé**.

## 2) Compléter les informations principales

Renseignez les champs essentiels :

- Prénom
- Nom
- Email professionnel
- Date d'entrée
- Poste

> Conseil : vérifiez l'orthographe de l'email, il sera utilisé pour les notifications.

## 3) Configurer le contrat

Dans la section contrat :

1. Choisissez le type de contrat (CDI, CDD, etc.).
2. Ajoutez la date de début.
3. Indiquez la rémunération de base.

## 4) Valider la création

- Relisez les informations.
- Cliquez sur **Enregistrer**.

Une fois validé, l'employé apparaît dans la liste et vous pourrez compléter les documents administratifs.

---

Si vous avez un doute, contactez le support via la page **Support**.
